# Velo Code Samples

A collection of custom Wix Velo (JavaScript) code I've written for client projects —
backend functions, booking logic, API integrations, and SEO automation. Since Wix
Studio sites live on Wix's own platform, this repo is where I share the actual code
behind the sites, for anyone evaluating my development skills directly.

## Why This Repo Exists
Most of my work is delivered inside the Wix Studio editor, which isn't visible on
GitHub by default. This repo pulls out the reusable, non-client-confidential logic
so recruiters and clients can see real code, not just finished screenshots.

## What's Inside

### 📅 booking-availability/
Backend Velo functions that check calendar availability and manage booking slots,
including the logic behind a Telegram-connected availability bot.

### 🔌 api-integrations/
Examples of connecting Wix sites to external services (Google Calendar, third-party
APIs) via Velo backend web modules.

### 🔍 seo-automation/
Scripts used to automate structured data, meta tag generation, and SEO audits for
client Wix sites.

### 🛒 ecommerce-checkout/
Custom checkout and booking flow logic built on top of Wix's eCommerce APIs.

## Tech Stack
`Velo (JavaScript)` `Wix Data API` `Wix HTTP Functions` `Google Calendar API`
